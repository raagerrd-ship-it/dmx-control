## 3. En idé: sökljusets radblink högst en gång per takt (DMX_SOK_TAKT=1) - FÖRKASTAD av domaren
Patch: tools/natt/prov/sokljus-takt-20261111.patch (5 rader i src/effects/sokljus.ts). Av-läget md5-identiskt (trace lang1021).
| | bas | prov |
|---|---|---|
| sökljusets spridning (lang1021) | 0,053 | **0,214** |
| lampspr lang1021 / pop / mega | 0,239 / 0,305 / 0,369 | 0,272 (+13,8 %) / = / 0,379 (+2,8 %) |
| rA / rK lang1021 | 0,329 / 0,271 | 0,322 / 0,265 |
| domaren v3 övning | - | **-0,8** (takt -1,3, dynamik -0,4, koreografi -1,1), ingen DISK |
| domaren v3 kontroll | - | **-0,5** (takt -0,8, dynamik -0,6, koreografi -0,2), ingen DISK |
Regeln (grundmålet): godkänd = domaren + utan DISK. Den gav minus i båda mängderna -> koden återställd (md5 = före).
Varför minus: radblinken på varje virvelslag är det som bär sökljusets takt mot basen; strålen ensam rör sig en gång per takt.
Domaren ser inte en stråle. Ägarens öga får avgöra om patchen ska provas - annars är rätt väg att dirigenten inte väljer
sökljuset när virveln slår tätt (tempo/FIT), eftersom effekten godkändes i lugna partier.
