# Remixkort - tvavagar runda 2 (en PRIORITET per kort, inte värden)

a1 r-robust: det som håller på kontrollmängden (andra låtar, tempon, breaks) - välj delar vars vinst inte hänger på ett fåtal klipp.
a2 r-md5: bara delar med bit-identiska DMX-värden (md5 lika) - maximal snabb väg utan att ljuset ändras alls.
a3 r-pi: Pi:ns verklighet - motorn är låst till 2 kärnor (CPUAffinity), ARM, Node 24: inga snurrande väntlägen, så få trådar
   som möjligt; bevisa att workern hinner med ändå.
a4 r-portbar: det som går att porta till lotus (samma delade analysator, lotus har inte beatFeed/taktvägen) utan profilvärden
   och utan att lotus ljus ändras.
a5 r-ljus: det ögat ser mest i ladan (ettan, låtgräns, sektioner) - långsamma vägens kvalitet där den syns i ljuset.
a6 r-kvalitet: långsamma vägen maximal över alla 16 mått - och ljusdomaren ska godkänna.
a7 r-minsta: minsta diff som tar flest mått - varje rad ska bära poäng.
a8 r-egen: din runda 1-idé som kärna + det ur idébanken som kompletterar den bäst.
